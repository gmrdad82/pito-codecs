# Security

## Supported versions

Fixes land on main and ship in the next release. Only the latest release gets
them; depend on a newer tag to pick one up.

## Reporting a vulnerability

Please report it privately, not in a public issue. On the repository's
[Security tab](https://github.com/gmrdad82/pito-codecs/security), choose
**Report a vulnerability**, or open the form directly at
<https://github.com/gmrdad82/pito-codecs/security/advisories/new>. Say what you
found, the version or commit, and how to reproduce it. A decoder that panics,
hangs or reads out of bounds on a crafted file is in scope; where you can share
one, a small input file that shows it helps most.

The report stays private between you and the maintainer until a fix is
released. You will hear back on the advisory, and the fix and its release are
credited to you unless you would rather they were not.
